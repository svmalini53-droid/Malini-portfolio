# **App Name**: PortfolioPlus

## Core Features:

- Resume Display: Display the user's resume in an easily viewable format.
- Resume Download: Allow visitors to download the resume in a common file format.
- Contact Form Response: Implement a contact form that provides a clear confirmation message upon submission.
- Generative Bio Enhancement: Allow the user to re-write the 'about me' text using a generative AI tool.

## Style Guidelines:

- Primary color: Light blue (#38bdf8) to maintain consistency with the existing portfolio site's theme. Its association with sky evokes clarity and trustworthiness.
- Background color: Dark gray (#0f172a) - very desaturated, to preserve the dark color scheme from the original design.
- Accent color: Purple (#818cf8) - to complement the light blue and create a visually appealing contrast.
- Font: 'Inter' sans-serif for both body and headlines to maintain consistency and readability.
- Use simple, consistent icons from Font Awesome to enhance visual communication.  Specifically use the github and linked in icons the user specified.
- Maintain a clean and structured layout that adapts well to different screen sizes using Tailwind CSS grid and flexbox utilities.
- Subtle hover effects and transitions to provide feedback and improve the user experience.
